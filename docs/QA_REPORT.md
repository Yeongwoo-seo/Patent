## 4. 알려진 버그/이상 (발견 즉시 수정한 것 포함)

- (수정됨) `gradeAttempt`의 수치 채점이 빈 문자열(`''`)을 `Number('')===0`으로
  오인해 정답 처리할 뻔한 문제 — 빈 답안은 `unknown`으로 명시 처리하도록 수정,
  회귀 테스트 추가.
- (수정됨) DOM 헬퍼에서 `style` 문자열을 `Object.assign`으로 직접 대입하면
  strict mode에서 `TypeError`가 발생하는 문제 — `style.cssText` 대입으로 수정.
- (수정됨) 데모 데이터의 `LearningItem.verification`이 전부 `'unverified'`로
  설정되어 있어 검증된 과학 항목까지 "오늘의 퀘스트" 후보에서 빠지던 문제 —
  물리/화학/생물 6개 항목만 실제 채점 스펙과 일치하게 `'verified'`로 수정.
- (수정됨) 수입기의 자산 매칭이 basename만 봐서, 실제 기출 콘텐츠처럼 서로
  다른 과목 폴더에 같은 파일명(`0006.webp`)이 있으면 하나가 다른 하나를
  덮어쓰는 문제 — 사용자에게 보고되기 전에 자체 점검(`find | xargs basename |
  uniq -d`)으로 발견. `assetTextByBasename/assetBinaryByBasename` →
  `assetTextByPath/assetBinaryByPath`(패키지 루트 기준 전체 상대경로)로
  바꾸고 파일 입력을 `webkitdirectory`로 전환해 수정, Chromium에서 두
  `0006.webp`가 각자 올바른 바이트 크기로 분리 저장됨을 재확인.
- (수정됨) 문항 결과 화면이 해설 구간을 `EvidenceLink.explanationSegmentId`
  경로로만 찾고 있었는데, 이 필드는 "제공 해설" 하나만 가리켜서 같은 판단
  단위의 "AI 추론" 해설 구간이 화면에 전혀 나타나지 않는 문제 — 민법 샘플
  통합 중 둘 다 실제로 존재하는 데이터를 보고 발견(자연과학 샘플도 같은
  구조라 동일하게 누락되고 있었을 것). `ExplanationSegment.analysisUnitId`로
  직접 조회하도록 고쳐 Chromium에서 "제공 해설(공식 아님)"과 "AI
  추론(미검증)" 배지가 함께 나오는 것을 재확인.
- (수정됨) 자연과학 720문항 전체 변환 중 발견: 분석 단위의 88%(1,213/1,370)는
  아직 확정 근거 연결이 없는 "후보 매핑만" 단계라 `evidence_link_review`
  객체가 없는데, 변환기가 이를 무조건 있다고 가정해 `KeyError`로 전체 변환이
  실패하는 문제 — 4개 공식 샘플은 전부 검토가 끝난 문항이라 이 경로를 타지
  않아 그동안 드러나지 않았다. 최상위 `review_status` 필드로 폴백하고 유일한
  새 값을 기존 `EvidenceVerificationStatus.not_reviewed`에 매핑해 수정,
  720문항 전체 재변환·재검증.
- (수정됨) 같은 720문항 변환 검증 중 발견: `ExamQuestion.currentLawAnswer`
  (민법 통합 때 추가한 4번째 답 축)를 화면이 무조건 `.value`로 접근했는데,
  이 필드가 아예 없는 자연과학 데이터에서 `Cannot read properties of
  undefined` 런타임 오류(Chromium pageerror)로 실제로 재현됐다 — 타입을
  선택 필드로 바꾸고 화면 코드를 옵셔널 체이닝으로 수정, 720문항 중 21개
  표본 O/X 제출로 재확인(pageerror 0건).
